## 📂 pruebas_limpieza Data

La carpeta `data\pruebas_limpieza` contiene las distintas etapas de preprocesamiento que atravesaron
los datos, desde los primeros intentos de limpieza hasta un conjunto de datos semi preprocesesados.

Esto incluye 3 carpetas, las cuales, a pesar de constituir por si mismos conjuntos de datos
obsoletos, son mantenidos como mero archivo.
